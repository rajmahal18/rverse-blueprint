# Phase 4 handoff — Data, Forms & Workflows

Blueprint v0.7 expands App Setup from 302 to 406 schema-driven decisions and from 18 to 23 sections.

## Added sections
- Data model & integrity
- Forms & input
- Tables, search & views
- Workflow & approvals
- Files & collaboration

## Usability rules preserved
- Recommended defaults remain complete; users configure exceptions rather than fill a questionnaire.
- Advanced settings remain hidden unless requested/searched.
- Parent toggles hide irrelevant child settings without deleting custom overrides.
- Search, section jump navigation, sub-groups, and Customized-only mode automatically work with all Phase 4 settings.
- Existing Phase 1–3 setting IDs and backup schema remain compatible.

Data modeling, IDs/references, relationships, lifecycle, integrity, concurrency, transactions/idempotency, retention, forms, validation, drafts/autosave, dynamic fields, field types, submission safety, list/table behavior, search/filter/saved views, workflow states, assignments, approvals, SLA/escalation, tasks, attachments, comments, activity, concurrent collaboration, and bulk import behavior.
