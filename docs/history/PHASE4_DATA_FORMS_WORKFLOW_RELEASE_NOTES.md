# Blueprint v0.7 — Phase 4 release notes

Phase 4 turns the generic records/workflow starter layer into a detailed product contract while keeping the default experience low-effort.

- 406 total schema-driven App Setup decisions
- 23 App Setup sections
- 5 new dedicated Phase 4 sections
- Deep data integrity and record lifecycle controls
- Full form/input behavior including drafts, autosave, conditional fields, validation, review and duplicate-submit protection
- Table/list/search/filter/saved-view configuration
- Explicit workflow state, assignment, approval, SLA, escalation and task behavior
- Attachment, comment, activity and collaboration controls
- Bulk import mapping, preview, duplicate and failure policies
- Additional warnings for client-only validation, app-only uniqueness, unsafe concurrent edits, unrestricted workflow transitions and imports without preview
- No backup schema bump; existing projects normalize into new contextual defaults automatically
