# RVerse Blueprint v0.30.0 — Visual Preview Studio MVP

## Release scope

v0.30 implements **Phase 5** of the Visual Intelligence master program only. Blueprint can now show the generated product/site direction as a configurable living preview before implementation. This release deliberately stops before v0.31 approval semantics: there is no final Approved Visual Contract or immutable visual approval state yet.

## What changed

### 1. Visual Preview Studio becomes the primary design decision surface

A new `Preview Studio` workspace sits between Visual Studio and Generated Spec. It consumes the existing intelligence chain rather than creating a parallel design engine:

```text
Visual Director
→ Pattern Explorer 2.0
→ Page Composition Intelligence
→ Visual Preview Studio
```

Raw Visual Studio controls remain available, but the default design workflow can now be recognition-first: compare, inspect, refine, and intentionally save.

### 2. A / B / C direction comparison

Preview Studio uses the first three existing Pattern Explorer recommendations as its A/B/C proposals.

- direction A/B/C names and DNA come from Pattern Explorer
- previewing a direction is reversible local state
- choosing a direction does not activate functional scope
- when explicitly saved, the selected Visual DNA is persisted and only currently compatible bundled visual patterns are added

There is no independent preview recommendation engine competing with v0.27/v0.28.

### 3. Desktop / tablet / mobile preview modes

The live stage supports:

- Desktop
- Tablet
- Mobile

Device mode changes are preview state only. The responsive plan is deliberate rather than a scale transform:

- desktop uses wide-composition guidance
- tablet uses adaptive-composition guidance
- mobile consumes the page model's explicit `mobileRecomposition` rules from v0.29

Canonical mobile previews alter hierarchy/order and interaction presentation where required instead of merely shrinking desktop geometry.

### 4. Multi-page preview with scope visibility

The page selector renders the major pages generated by Page Composition Intelligence.

Every preview retains its existing scope state:

- `implementation` pages represent currently authorized structured scope
- `advisory` pages remain visibly advisory visual proposals

Previewing an advisory page never upgrades it to implementation scope.

### 5. Domain-specific living prototypes

The MVP avoids funneling all projects through one universal demo page. Dedicated composition renderers preserve the benchmark families:

- **Automotive / ADW** — image-led storefront, product/upgrades, location/contact language
- **Clinic / EMR** — calm operational work queue and clinical information hierarchy
- **Government / HRMS** — institutional workforce and personnel-record hierarchy
- **Booking** — availability/selection-first transactional composition
- **Sports** — live state, match/score, schedule/standings prominence
- **Portfolio** — authored work and case-study narrative

A generic fallback exists for unmatched contexts, but canonical product families retain their own visual/product grammar.

### 6. High-value live visual refinements

Preview Studio exposes a deliberately small set of controls that materially affect recognition:

- typography character/family direction
- heading weight
- body weight
- color/accent behavior
- density
- radius/geometry
- spacing
- imagery treatment
- section structure
- navigation variant

This is not a Figma-style freeform editor and does not duplicate every advanced Visual Studio setting.

### 7. Intentional preview persistence

Preview state and Blueprint design authority are separated.

The following remain reversible/transient until explicitly saved:

- device mode
- active preview page
- A/B/C comparison selection
- unsaved live refinements

Only deliberate **Save refinement to Blueprint** / direction actions persist Visual DNA. This prevents simple inspection actions from silently becoming product/design decisions.

### 8. Navigation variant becomes persisted Visual DNA

New structured Visual DNA setting:

- Auto / Recommended
- Top bar
- Compact header
- Sidebar
- Bottom dock

The value:

- normalizes safely for older projects
- persists through project/workspace backup state
- is editable from Visual Studio
- is refinable from Preview Studio
- appears in the full Visual DNA contract
- appears in the compact primary implementation contract

Because this adds a persisted DNA field, backup schema advances to **v13**. Backups v2–v13 remain importable.

### 9. Media Assistance is reflected in preview

Preview placeholder media is deterministic and domain-aware, using the existing Visual Director media direction.

Examples include automotive product/detail media, clinical context, institutional/workforce context, court/booking imagery, sports/event imagery, and portfolio/project media.

If Media Assistance resolves to no placeholder imagery, the preview respects that decision instead of generating a fake image surface merely to make the preview look richer.

### 10. Qualitative preview warnings

Preview Studio surfaces recognition-oriented warnings for relevant current state such as:

- advisory page scope
- visual contradictions
- non-clear page visual-quality review dimensions
- anti-homogeneity risk

Warnings remain qualitative (`review` / `risk`) and explanatory. v0.30 does not introduce a fabricated preview-quality, confidence, originality, or polish score.

### 11. Scope authority is preserved

Preview Studio is visual/presentational authority only.

It cannot silently turn on:

- Portfolio / Marketing
- Commerce / checkout
- Payments
- Booking
- Admin
- CRM
- Inventory
- user accounts
- or any other optional product module

The v0.25 rule remains unchanged:

```text
Suggested != On
```

### 12. Navigation and flow integration

- Core navigation now includes **Preview Studio**.
- Visual Studio's next-step CTA leads to Preview Studio before Generated Spec.
- Mobile bottom navigation exposes Preview directly as a primary step.
- Generated Spec and compiler remain downstream of intentionally saved Blueprint state.

### 13. Metadata / schema updates

- package version: **0.30.0**
- generated Blueprint version: **0.30.0**
- structured JSON schema: **v18**
- backup schema: **v13**
- accepted backup imports: **v2–v13**

## Main architecture changes

### New `src/data/previewStudio.ts`

Central preview intelligence layer:

- consumes Pattern Explorer recommendations for A/B/C
- derives domain-aware placeholder-media state
- derives preview warning state
- derives desktop/tablet/mobile responsive-preview plans
- carries the explicit scope guardrail into Preview Studio

### New `src/components/PreviewStudio.tsx`

Provides:

- Preview Studio shell/control panel
- A/B/C selector
- multi-page selector
- device selector
- high-value live refinement controls
- explicit persistence action
- preview warnings
- domain-specific renderers
- mobile recomposition branches

### `src/data/visualDna.ts`

Adds persisted `navigationVariant` and normalization/contract serialization.

### `src/components/VisualStudio.tsx`

Adds the same navigation-variant control to the structured raw Visual Studio surface.

### `src/App.tsx`

- adds Preview Studio as a first-class view
- derives current visual contradictions for preview review
- commits preview refinements explicitly
- applies only compatible bundled patterns on deliberate direction save
- preserves App Setup untouched by preview actions
- advances backup metadata to v13 / Blueprint metadata to 0.30.0
- advances structured JSON to v18
- includes saved navigation variant in the compact implementation contract

### `scripts/visual-preview-studio-regression.mjs`

Adds the Phase 5 regression gate.

### Environment limitation

The release ZIP intentionally does not include `node_modules`. This sandbox does not have the project's React/Vite dependency tree installed, and offline `npm ci` cannot complete because required npm packages are not cached. Therefore a dependency-backed full application `npm run typecheck` / Vite production build cannot be truthfully claimed here.

On a normal local checkout, run:

```bash
npm ci
npm run typecheck
npm run build
npm test
```

## Phase boundary

v0.30 ends at:

```text
Describe
→ Recommend
→ Preview
→ Refine
→ Save mutable visual state
```

It intentionally does **not** implement:

- final visual approval
- an immutable/stable Approved Visual Contract
- `approved_preview` as compiler authority
- approval-driven compiler handoff

Those are v0.31 responsibilities.
